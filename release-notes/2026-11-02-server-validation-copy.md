Server validation messages now explain root-folder conflicts, failed list retrieval, and factory resets more clearly in translated language. Additional server validation and integration errors now have more consistent translations for connection, credential, media-selection, and quality issues.

qBittorrent category validation now explains that values cannot contain a backslash or `//`, or start or end with `/`, in the available translations.
