Bookshelf now has a **Formats** view for ebooks and audiobooks together. ChaptarrNG groups records only when they share a recognized work-level provider ID; each format keeps its own progress, monitoring control, and detail page, and bulk monitoring applies to both formats. From a book's details, users can also open a tracked record in the other format or add the missing format when it is not already tracked.

The combined view has a clear empty-library prompt, explains that bulk monitoring affects both formats, and offers a retry action if the shelf fails to load.
